## 发布限制

### 桌面产品 1.3.0

- 已执行 `npm.cmd run dist`，成功生成 Windows NSIS 安装包 `desktop/electron/dist/OpticsLab Setup 1.3.0.exe`（77,254,416 字节）及 blockmap；未签名，符合当前 `signAndEditExecutable: false` 的桌面构建配置。
- 桌面资源已由 `prepare:assets` 同步至 `desktop/electron/app`，因此安装包与仓库中的物理引擎、组件和 UI 更新一致。
- electron-builder 仍提示缺少 `author` 和 Windows 品牌图标；这不影响安装、运行或构建产物完整性，但在正式品牌发布前应补充签名、作者元数据和专用 `.ico` 图标。

- 默认的 `npm.cmd audit --audit-level=moderate` 仍会被配置的 `https://registry.npmmirror.com` 阻塞，因其不支持 npm security advisory 批量接口并返回 `404 [NOT_IMPLEMENTED]`。本轮已使用临时官方 registry 完成同等审计并得到 0 漏洞结果；未执行会修改依赖树的 `npm audit fix`。
- 物理模型的声明仍遵循验证矩阵：非球面和 GRIN 透镜为实验性/部分验证，前者仅验证解析面形与近轴折射，后者仅验证解析径向轮廓与双向近轴传输；厚透镜为标量几何与非偏振 Fresnel 模型；标记为 `visual_only` 的组件不应被表述为定量物理仿真。
- 设计 DOCX 已通过结构检查；环境中没有 LibreOffice/soffice，无法执行 DOCX 渲染成图片后的视觉复核。
